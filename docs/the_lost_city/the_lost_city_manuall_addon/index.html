Manuall Addons Creation

Explains how to create simple addons for The Lost City mod.

Installation

if you already mande some mods for minecraft, you can skip this part. first you need to install ide for minecraft (recomned ide is IntelliJ IDEA)

After that launch ide and go to plugins to install Minecraft Development

Project Setup

create new project for version 1.20.1 forge, in project you need to create "libs" folder in main project folder and put there latest The Lost City mod version.

after that go to build.gradle in dependencies put:

flatDir {
    dir 'libs'
}

and

implementation files('libs/file_name.jar')

into dependencies.

Adding first building

In ressources folder create data/your_mod_id/structures/ (id that you choose when creating the project) in that folder put your nbt structures.

In main class:

public ClassName()
{
  API.addBaseToCity("your_mod_id:nbt_file_name");
}

Done, you can build your project and find mod file in build/libs/

More API features

API has many other features that you can use, just type API. and ide will show all possible variants
